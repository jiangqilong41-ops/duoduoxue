# presentations：10–15 分钟技能课程

本手册使用 presentations@26.715.12143 的 2026-07-20 本地脱敏快照。所有练习只使用合成材料与只读判断。
本手册中的“输出/成品/链接”均指提示词中应列出的预期结构与验收证据，不实际创建、上传、部署、发送或改变外部状态。

## PR01 插件总览

### 1. 用途

建议用时：10–15 分钟。

建立 presentations@26.715.12143 的技能地图，知道何时从总览路由到每个独立单元：presentations（Presentations:演示文稿）。

### 2. 适用与不适用场景

- 适用：先判断插件覆盖范围、skill 分工、输入输出和安全调用方式。
- 不适用：不要把所有任务都路由到同一个 skill，也不要把插件总览当成执行器。

### 3. 输入/输出

- 输入：manifest、canonical skill 清单、每个 SKILL.md 与相邻 agents/openai.yaml 的非敏感元数据。
- 输出：能为合成场景选出正确入口，解释排除理由，并记录停止条件。

### 4. 最小调用模板

~~~
检查插件 presentations 的技能地图。只输出候选 skill、选择理由、所需输入和停止条件；不要调用工具、安装依赖或改变外部状态。
~~~

### 5. 边界与风险

固定使用 presentations@26.715.12143 的 local-sanitized 快照，日期为 2026-07-20。练习不读取凭证、客户数据或运行态秘密，也不自动发送、发布、部署或付费。

### 6. 提示词练习

~~~
合成场景：虚构团队描述一个与 presentations 相关的任务。请列出至多两个候选 skill，说明选择/排除理由；只做路由分析，不执行工具。
~~~

### 7. 可观察验收清单

- [ ] 能说出插件名、版本与 skill 数量（1）。
- [ ] 知道第一课是总览，后续每个 canonical skill 各占一个单元。
- [ ] 调用记录同时包含插件名、slug 和 display name。
- [ ] 输出只含路由、理由和停止条件，没有真实外部副作用。

## PR02 Presentations:演示文稿

### 1. 用途

建议用时：10–15 分钟。

创建或编辑 PowerPoint/Google Slides deck，并遵循受众叙事、低密度布局、字体和重叠检查规则。 本单元训练的核心判断是：场景明确落在上述用途时，选择 presentations，而不是无差别调用插件。

### 2. 适用与不适用场景

- 适用：创建或编辑 PowerPoint/Google Slides deck，并遵循受众叙事、低密度布局、字体和重叠检查规则。
- 不适用：任务缺少关键输入、要求越过以下边界，或实际目标属于另一个 skill：先读内容质量与叙事规则；观众可见内容不得暴露内部计划；必须修复所有未预期重叠，不默认发布外部文件。

### 3. 输入/输出

- 输入：受众、叙事目标、模板或品牌约束、素材、页面比例和输出格式。
- 输出：可编辑 deck、渲染预览及溢出/重叠/字体验收记录。

前置依赖：按需提供 artifact-tool 与渲染/检查工具；练习可只做路由，不执行导出。

### 4. 最小调用模板

~~~

~~~

### 5. 边界与风险

先读内容质量与叙事规则；观众可见内容不得暴露内部计划；必须修复所有未预期重叠，不默认发布外部文件。 任何真实账户、客户数据、凭证或不可逆外部写入都不属于本单元练习。
