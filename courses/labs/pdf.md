# pdf 实验手册

来源快照：`pdf@26.715.12143`（2026-07-20）。所有练习仅使用合成 fixture 和只读判断。
合成 fixture 约定：`<synthetic-fixture>` 是占位符，不是 PDF 路径；每节至少替换为两页虚构报告文字、页面尺寸、字体和表格约束。练习只检查读取/渲染方案，不读取或生成真实 PDF。
本手册中的“输出/成品/链接”均指提示词中应列出的预期结构与验收证据，不实际创建、上传、部署、发送或改变外部状态。
建议用时：每个单元 10–15 分钟。

## PF01 PDF 插件总览

### 1. 用途

把以 PDF 为输入或最终产物且视觉布局重要的请求路由到 PDF skill。

### 2. 适用与不适用场景

- 适用：用户要读取、创建、检查、渲染、验证或提取 PDF。
- 不适用：用户需要持续编辑的 Word 文档或带公式的工作簿。

### 3. 输入/输出

- 输入：PDF 文件或内容、阅读或创建目标、页面范围和布局验收要求。
- 输出：明确的 PDF skill 路由、页面检查范围和最终 PDF 交付要求。

### 4. 最小调用模板

```text
@pdf
请使用 @pdf（PDF 插件总览；skill slug: 插件入口）。
任务：基于下方合成材料，把以 PDF 为输入或最终产物且视觉布局重要的请求路由到 PDF skill。
材料：<synthetic-fixture>
```

### 5. 边界与风险

插件入口不代替页面渲染；文本提取结果不能证明页面布局正确。课程练习不得读取真实客户数据、凭据或生产状态，也不得发送、部署或写入外部系统。

### 6. 提示词练习

```text
@pdf
这是一个完全虚构的文件练习：<synthetic-fixture>。
请先判断是否适用，再输出明确的 PDF skill 路由、页面检查范围和最终 PDF 交付要求。
不要把抽取出的纯文本当作完整视觉验证。
```

## PF02 PDF:PDF 文件

### 1. 用途

用适合的库读取或生成 PDF，再用 Poppler 渲染每页并检查布局、字体、表格与图像。

### 2. 适用与不适用场景

- 适用：PDF 内容阅读或交付需要保留页面结构、图表、表格、页眉页脚和视觉质量。
- 不适用：用户只需要可编辑 DOCX，且没有 PDF 输入或输出。

### 3. 输入/输出

- 输入：源 PDF 或待生成内容、页面尺寸、字体与版式要求、输出位置。
- 输出：PDF 文本/结构检查、逐页 PNG 渲染和视觉验收方案（练习不读取或生成 PDF）。
- 前置依赖：真实执行需要 bundled runtime 和 Poppler 渲染工具；课程不创建 PDF。

### 4. 最小调用模板

```text
@pdf
请使用 $pdf:pdf（PDF:PDF 文件；skill slug: pdf）。
任务：基于下方合成材料，写出用适合的库读取或生成 PDF、再用 Poppler 渲染并检查布局的方案；只列预期证据，不读写文件。
材料：<synthetic-fixture>
```

### 5. 边界与风险

pdfplumber 或 pypdf 的抽取只做内容检查；最后一次有意义更新后必须重新渲染，不能留下工具占位符。课程练习不得读取真实客户数据、凭据或生产状态，也不得发送、部署或写入外部系统。

### 6. 提示词练习

```text
$pdf:pdf
这是一个完全虚构的文件练习：<synthetic-fixture>。
请先判断是否适用，再输出文本/结构检查、逐页 PNG 渲染和视觉验收方案；不要读取或生成 PDF。
不要只检查文件存在或抽取文本便交付。
```
