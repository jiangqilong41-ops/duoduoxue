# openai-templates：10–15 分钟技能课程

本手册使用 `openai-templates@0.1.0` 的 `2026-07-20` 本地脱敏快照。所有练习只使用合成材料与只读判断。
本手册中的“输出/成品/链接”均指提示词中应列出的预期结构与验收证据，不实际创建、上传、部署、发送或改变外部状态。


## OT01 插件总览

### 1. 用途

建议用时：10–15 分钟。

建立 `openai-templates@0.1.0` 的技能地图：在用户明确选择参考模板时，调用相应文档、演示或电子表格能力并保留模板视觉系统。

### 2. 适用与不适用场景

- 适用：需要先判断插件覆盖范围、skill 分工和安全调用方式。
- 不适用：用户未选择模板或只需自由设计时，不应擅自套用某个默认模板。

### 3. 输入/输出

- 输入：插件 manifest、canonical skill 清单、相邻 `agents/openai.yaml` 的显示名与调用策略。
- 输出：能解释总览课与 20 个 skill 单元的对应关系，并为合成场景选出正确入口。

### 4. 最小调用模板

```text
检查插件 openai-templates 的技能地图。只输出候选 skill、选择理由、所需输入和停止条件；不要调用工具、安装依赖或改变外部状态。
```

### 5. 边界与风险

固定使用 `local-sanitized` 的 `0.1.0` 快照；课程示例不读取凭证、客户数据或运行态秘密，也不自动发送、发布、部署或付费。

### 6. 提示词练习

```text
合成场景：一家虚构团队描述了一个与本插件相关的任务。请列出至多两个候选 skill，说明为什么选择或排除；只做路由分析。
```

### 7. 可观察验收清单

- [ ] 能说出插件名、版本与 skill 数量。
- [ ] 知道第一课是总览，后续每个 canonical skill 各占一个单元。
- [ ] 调用记录同时包含插件名、slug 和 display name。
- [ ] 输出只含路由、理由和停止条件，没有真实外部副作用。

## OT02 OpenAI Templates:分析仪表盘

### 1. 用途

建议用时：10–15 分钟。

用分析仪表盘模板创建含获客、留存、收入和转化图表的电子表格。本单元训练的核心判断是：场景属于“用户明确选择“分析仪表盘”时，用保留的参考模板创建电子表格”时选择它。

### 2. 适用与不适用场景

- 适用：用户明确选择“分析仪表盘”时，用保留的参考模板创建电子表格。
- 不适用：用户没有选择该模板，或需求是无需模板约束的自由设计。

### 3. 输入/输出

- 输入：用户提供的内容、可核实来源、保留的参考文件与预装电子表格能力。
- 输出：保留模板结构和视觉系统、经过渲染验证的电子表格成品。

前置依赖：对应的预装文档、演示或电子表格能力，以及插件保留的参考模板文件。

### 4. 最小调用模板

```text
使用插件 openai-templates，显式调用 $openai-templates:artifact-template-analytics-dashboard（OpenAI Templates:分析仪表盘）。输入均为合成材料；只输出执行方案、停止条件和验收清单，不执行写入、发送、发布、部署、安装或付费操作。
```

### 5. 边界与风险

参考文件保持不变；不得为填满版位编造事实，缺所需预装能力时停止而非重建模板。任何真实账户、客户数据、凭证或外部写入都不属于本单元练习。

### 6. 提示词练习

```text
合成场景：用户明确选择“分析仪表盘”时，用保留的参考模板创建电子表格。请先复述所需输入，再说明为何选择 $openai-templates:artifact-template-analytics-dashboard、何时应停止，并给出三项可观察验收标准。不要实际调用工具。
```
