# data-analytics：10–15 分钟技能课程

本手册使用 `data-analytics@0.2.8-13ceeea1f599` 的 `2026-07-20` 本地脱敏快照。所有练习只使用合成材料与只读判断。
本手册中的“输出/成品/链接”均指提示词中应列出的预期结构与验收证据，不实际创建、上传、部署、发送或改变外部状态。


## DA01 插件总览

### 1. 用途

建议用时：10–15 分钟。

建立 `data-analytics@0.2.8-13ceeea1f599` 的技能地图：把产品或业务问题路由到上下文收集、数据质量、诊断、KPI、分析、可视化、报告与发布工作流。

### 2. 适用与不适用场景

- 适用：需要先判断插件覆盖范围、skill 分工和安全调用方式。
- 不适用：插件入口负责判断工作流，不能把缺失的权威数据源或未验证证据当作事实。

### 3. 输入/输出

- 输入：插件 manifest、canonical skill 清单、相邻 `agents/openai.yaml` 的显示名与调用策略。
- 输出：能解释总览课与 18 个 skill 单元的对应关系，并为合成场景选出正确入口。

### 4. 最小调用模板

```text
检查插件 data-analytics 的技能地图。只输出候选 skill、选择理由、所需输入和停止条件；不要调用工具、安装依赖或改变外部状态。
```

### 5. 边界与风险

固定使用 `local-sanitized` 的 `0.2.8-13ceeea1f599` 快照；课程示例不读取凭证、客户数据或运行态秘密，也不自动发送、发布、部署或付费。

### 6. 提示词练习

```text
合成场景：一家虚构团队描述了一个与本插件相关的任务。请列出至多两个候选 skill，说明为什么选择或排除；只做路由分析。
```

### 7. 可观察验收清单

- [ ] 能说出插件名、版本与 skill 数量。
- [ ] 知道第一课是总览，后续每个 canonical skill 各占一个单元。
- [ ] 调用记录同时包含插件名、slug 和 display name。
- [ ] 输出只含路由、理由和停止条件，没有真实外部副作用。

## DA02 Data Analytics:数据质量分析

### 1. 用途

建议用时：10–15 分钟。

在分析或发布前评估表格与数据集的完整性、准确性和可信度。本单元训练的核心判断是：场景属于“评估数据集、查询结果或指标证据是否可信”时选择它。

### 2. 适用与不适用场景

- 适用：评估数据集、查询结果或指标证据是否可信。
- 不适用：要定义未来 KPI，或只需 QA 已完成的分析成品。

### 3. 输入/输出

- 输入：预期粒度、关键字段、时间窗口、来源和下游用途。
- 输出：带计数、比例、严重度、风险和最小修复建议的质量结论。

### 4. 最小调用模板

```text
使用插件 data-analytics，显式调用 $data-analytics:analyze-data-quality（Data Analytics:数据质量分析）。输入均为合成材料；只输出执行方案、停止条件和验收清单，不执行写入、发送、发布、部署、安装或付费操作。
```

### 5. 边界与风险

先确认粒度并比较比例；不得把原始 profiling dump 当成解释。任何真实账户、客户数据、凭证或外部写入都不属于本单元练习。

### 6. 提示词练习

```text
合成场景：评估数据集、查询结果或指标证据是否可信。请先复述所需输入，再说明为何选择 $data-analytics:analyze-data-quality、何时应停止，并给出三项可观察验收标准。不要实际调用工具。
```

建议用时：10–15 分钟。

通过 Sites 发布已验证的分析报告或仪表板成果。本单元训练的核心判断是：场景属于“把已验证的数据分析报告或仪表板发布到 Sites”时选择它。

### 2. 适用与不适用场景

- 适用：把已验证的数据分析报告或仪表板发布到 Sites。
- 不适用：分析产物尚未构建验证，或用户只要本地文件。

### 3. 输入/输出

- 输入：已验证 artifact、站点名称、发布生命周期能力与可分享范围。
- 输出：checkpoint/部署前检查方案、预期 Sites 链接字段和分享范围清单（练习不发布）。

前置依赖：已验证的 Data Analytics artifact 与完整可调用的 Sites 创建、checkpoint 和部署能力。

### 4. 最小调用模板

```text
使用插件 data-analytics，显式调用 $data-analytics:publish-artifact-to-sites（Data Analytics:分析成果发布）。输入均为合成材料；只输出执行方案、停止条件和验收清单，不执行写入、发送、发布、部署、安装或付费操作。
```

### 5. 边界与风险

真实流程只负责发布，不修补分析；没有合格产物或发布能力时应报告阻塞。练习只写发布前方案，不执行发布。任何真实账户、客户数据、凭证或外部写入都不属于本单元练习。

### 6. 提示词练习

```text
合成场景：把已验证的数据分析报告或仪表板发布到 Sites。请先复述所需输入，再说明为何选择 $data-analytics:publish-artifact-to-sites、何时应停止，并给出三项可观察验收标准。不要实际调用工具。
```

## DA18 Data Analytics:分析验证

### 1. 用途

建议用时：10–15 分钟。

检查分析逻辑、指标、图表和结论是否准确且有充分依据。本单元训练的核心判断是：场景属于“验证分析、图表、报告或建议是否准确且证据充分”时选择它。

### 2. 适用与不适用场景

- 适用：验证分析、图表、报告或建议是否准确且证据充分。
- 不适用：要调查底层原始数据的完整性、唯一性或新鲜度。

### 3. 输入/输出

- 输入：分析产物、计算、来源、方法、caveat 与核心主张。
- 输出：逐项核对后的问题、严重度、修复要求和是否可分享结论。

### 4. 最小调用模板

```text
使用插件 data-analytics，显式调用 $data-analytics:validate-data（Data Analytics:分析验证）。输入均为合成材料；只输出执行方案、停止条件和验收清单，不执行写入、发送、发布、部署、安装或付费操作。
```

### 5. 边界与风险

验证成品不等于重新分析所有底层数据；高影响主张必须追到证据。任何真实账户、客户数据、凭证或外部写入都不属于本单元练习。


## DA19 Data Analytics:数据可视化

### 1. 用途

建议用时：10–15 分钟。

设计、构建、修订并全面质检用于分析工作的定量图表与视觉呈现。本单元训练的核心判断是：场景属于“选择、构建、修订或 QA 定量图表与视觉呈现”时选择它。

### 2. 适用与不适用场景

- 适用：选择、构建、修订或 QA 定量图表与视觉呈现。
- 不适用：用户需要完整报告或仪表板的信息架构和发布。

### 3. 输入/输出

- 输入：分析问题、已审数据、比较关系、受众与交付表面。
- 输出：选择合理图形、诚实尺度、充分标签和最终表面检查结果。

### 4. 最小调用模板

```text
使用插件 data-analytics，显式调用 $data-analytics:visualize-data（Data Analytics:数据可视化）。输入均为合成材料；只输出执行方案、停止条件和验收清单，不执行写入、发送、发布、部署、安装或付费操作。
```

### 5. 边界与风险

图形服从比较问题；数据点过少时应补数据或换成更诚实的表述。任何真实账户、客户数据、凭证或外部写入都不属于本单元练习。
