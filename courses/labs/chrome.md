# Chrome：10–15 分钟技能课程

本手册使用 chrome@26.715.52143 的 2026-07-20 本地脱敏快照。<synthetic-fixture> 是虚构的本地页面、应用状态或项目结构；所有“操作、构建、发布、URL、证据”均指提示词中的预期结构，不实际登录、点击、输入、截图、写文件、推送或部署。

## CH01 Chrome 插件总览

### 1. 用途

建议用时：10–15 分钟。

建立 Chrome 路由地图：仅在用户明确选择 Chrome，或任务确实依赖其现有 tabs、登录会话或扩展时考虑该入口。

### 2. 适用与不适用场景

- 适用：需要先判断 Chrome 的入口、内部 skill 分工和授权边界。
- 不适用：把 Chrome 当成所有链接任务的默认入口，或在有专用 connector、API、CLI 时绕过它们。

### 3. 输入/输出

- 输入：用户是否明确指定 Chrome、任务是否依赖现有 Chrome 状态、目标 UI 操作和授权边界。
- 输出：Chrome 与专用接口的选择理由、认证阻塞处理、停止条件和预期可见证据。

### 4. 最小调用模板

~~~text
只分析 <synthetic-fixture>。为 Chrome 任务列出候选 skill、选择理由、所需输入和停止条件；不要实际调用浏览器、桌面或部署工具。
~~~

### 5. 边界与风险

课程只使用 <synthetic-fixture> 场景；不读取真实 tabs、登录会话、cookies、扩展、密码或本地存储。

### 6. 提示词练习

~~~text
合成场景：虚构团队描述一个 Chrome 相关任务。请判断是否适用，列出候选调用、排除理由与三项预期证据；只返回方案。
~~~

### 7. 可观察验收清单

- [ ] 能说出插件版本和 1 个 canonical skill。
- [ ] 能区分适用场景、非适用场景和停止条件。
- [ ] 输出只包含 <synthetic-fixture>、路由理由和预期证据。

## CH02 control-chrome

### 1. 用途

建议用时：10–15 分钟。

在用户明确要求 Chrome，或任务依赖其现有 tabs、登录会话或扩展时控制 Chrome 的可见 UI。

### 2. 适用与不适用场景

- 适用：用户明确点名 Chrome，或已确认必须使用 Chrome 的现有浏览器状态完成 UI 工作。
- 不适用：链接资源的语义操作可由专用 connector/API/CLI 完成；或者仅为绕过认证而换来源、搜索或切浏览器。

### 3. 输入/输出

- 输入：明确的 Chrome 选择、目标页面/UI 操作、需要的现有状态与认证停止条件。
- 输出：Chrome 路由理由、可见 UI 检查计划和预期证据；课程不读取或复用真实登录态。

前置依赖：只需 <synthetic-fixture>；它代表虚构的本地页面、应用状态或项目结构，不包含真实账户、凭证或外部状态。

### 4. 最小调用模板

~~~text
使用插件 chrome，显式调用 $chrome:control-chrome（control-chrome）。只分析 <synthetic-fixture>；输出路由理由、输入、停止条件和预期证据，不实际调用工具。
~~~

### 5. 边界与风险

浏览器发现必须只读，不检查 cookies、local storage、profiles、passwords 或 session stores。显式 Chrome 不可用时报告不可用；认证阻塞时请用户在 Chrome 登录，未经批准不切换浏览器。

### 6. 提示词练习

~~~text
合成场景：用户明确点名 Chrome，或已确认必须使用 Chrome 的现有浏览器状态完成 UI 工作。 请说明为何选择 $chrome:control-chrome（control-chrome）、何时不应使用，并给出三项可观察的预期验收证据。不要执行任何 UI、文件、账户或部署动作。
~~~

### 7. 可观察验收清单

- [ ] 调用句同时包含插件 chrome、调用名 control-chrome 和显示名 control-chrome。
- [ ] 能解释适用与不适用场景，而不是只背名称。
- [ ] 能复述输入、预期输出和停止条件。
