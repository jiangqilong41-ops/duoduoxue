# Codex 用户 Skills：Mac 实验手册

本手册覆盖 `$CODEX_HOME/skills` 的脱敏快照（课程正文只保留相对来源）。每节 10–15 分钟；只用合成 fixture、提示词和只读状态检查。不得安装、更新或实际执行 skill，不读取凭证、日志、状态库或客户数据。

总览课 GS01 建立调用证据层；GS02–GS18 覆盖 17 个用户 skill，GS19–GS24 覆盖 6 个 `.system` skill。每节都把 skill 当作有边界的工作流，不把路由器、配置器或安装器伪装成无条件执行器。

## GS01 Codex 用户 Skills 总览

### 1. 用途

建立“什么时候用哪个 skill”的判断框架：先辨认任务意图和输入，再核对正式调用名、界面展示名与来源，最后定义只读、可观察的验收证据。本课是后续 23 个 skill 单元的共同入口，不执行任何 skill。

### 2. 适用与不适用场景

- 适用：面对多个相邻 skill，需要比较触发边界、选择一个主入口并写出显式调用与停止条件。
- 不适用：把课程当作批量安装、更新、启用或实际运行 skill 的操作手册，或只想背目录名而不判断场景。

### 3. 输入/输出

- 输入：合成任务场景、任务意图、必要输入、候选 skill 的 `SKILL.md name`、`openai.yaml interface.display_name` 与相对来源路径。
- 输出：一个主 skill、排除相邻入口的理由、正式调用模板、预期输出、停止条件和可观察验收证据。
- 证据层：skill 可见、插件缓存、配置存在、已加载、已获信任、已授权和实际执行彼此不同，不能互相替代。
- 占位符：`<synthetic-fixture>` 仅代表不含真实数据的虚构值；练习不读取凭证、日志、状态库或客户数据。

### 4. 最小调用模板

```text
这是一个完全虚构的场景：<synthetic-fixture>。
请先说明任务意图和必要输入，再比较候选 skill，选择一个主 skill；调用名依据 SKILL.md 的 name，展示名依据相邻 openai.yaml 的 interface.display_name。
只返回选择理由、正式调用、预期输出、停止条件和可观察验收证据；不要安装、启用、发送、写入、部署或访问真实系统。
```

### 5. 边界与风险

不要因为文件可见、插件已缓存或配置文件存在，就声称 skill 已加载、获信任、获授权或实际执行；不要把路由器、配置维护器、审查器或安装器当作无条件执行器。练习只使用合成 fixture、提示词和只读状态检查，不读取 token、日志、历史、客户数据，不触发外部副作用。

### 6. 提示词练习

```text
面对“<synthetic-fixture>：用户要完成一项工作，但有三个相邻 skill 可选”的场景，使用 GS01 Codex 用户 Skills 总览方法。
1. 写出任务意图和必要输入；
2. 用 SKILL.md name 区分正式调用，用 openai.yaml interface.display_name 区分展示；
3. 选择一个主 skill，写一条排除理由；
4. 给出预期输出、停止条件和只读验收证据。
全程不安装或实际调用 skill，不访问真实系统。
```

### 7. 可观察验收清单

- [ ] 能先写出任务意图、必要输入和候选 skill 的边界，而不是按目录名盲选。
- [ ] 正式调用使用 `SKILL.md` 的 `name`；面向学习者的展示使用 `openai.yaml` 的 `interface.display_name`；来源保留相对路径。
- [ ] 能选择一个主 skill，并说明至少一个相邻入口为什么不适用。
- [ ] 预期输出、停止条件和验收证据均可由合成 fixture 与只读检查复核。
- [ ] 不把可见、缓存、配置存在、加载、信任、授权或执行混为同一证据层。
- [ ] 全程没有安装、启用、发送、写入、部署、付费或真实数据访问。

## GS02 Local:学术研究套件

### 1. 用途

把深度研究、论文写作、审稿、完整研究管线或实验规划请求路由到一个最匹配的内部 WORKFLOW.md。这是一个研究工作流路由器，本单元只训练选择、显式调用记录和停止条件。

### 2. 适用与不适用场景

- 适用：需要文献综述、研究问题收敛、论文写作或审稿等学术流程，并能说明当前研究阶段。
- 不适用：只是一般事实问答，或宽泛论文主题尚未收敛为可回答的研究问题却要求立即写大纲。

### 3. 输入/输出

- 输入：研究意图、研究问题成熟度、已有文献或数据、当前阶段与期望交付物。
- 输出：一个明确的内部工作流和模式、当前阶段产物、下一道可选或强制门槛。
- 来源：.codex/skills/academic-research-suite/SKILL.md（快照 2026-07-20）。

## GS06 Local:CLI 创建器
