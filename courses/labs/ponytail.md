# ponytail：10–15 分钟技能课程

本手册使用 `ponytail@4.8.4` 的 `2026-07-20` 本地脱敏快照。所有练习只使用合成材料与只读判断。
本手册中的“输出/成品/链接”均指提示词中应列出的预期结构与验收证据，不实际创建、上传、部署、发送或改变外部状态。


## PT01 插件总览

### 1. 用途

建议用时：10–15 分钟。

建立 `ponytail@4.8.4` 的技能地图：在编码、审查和全库盘点中优先选择 YAGNI、现有代码、标准库、平台原生能力与最短正确实现。
Ponytail Hook 是插件携带的生命周期集成，不是第七个 skill，也不是可单独调用的执行器。

### 2. 适用与不适用场景

- 适用：需要先判断插件覆盖范围、skill 分工和安全调用方式。
- 不适用：非编码写作或知识问答不应套用 Ponytail 编码模式。

### 3. 输入/输出

- 输入：插件 manifest、canonical skill 清单、相邻 `agents/openai.yaml`，以及 `hooks/claude-codex-hooks.json` 的事件/matcher 结构。
- 输出：能解释总览课与 6 个 skill 单元的对应关系，并区分 Hook 的携带、信任、启用和实际执行四类证据。

### 4. 最小调用模板

```text
检查插件 ponytail 的技能地图。只输出候选 skill、选择理由、所需输入和停止条件；不要调用工具、安装依赖或改变外部状态。
```

### 5. 边界与风险

固定使用 `local-sanitized` 的 `4.8.4` 快照；课程示例不读取凭证、客户数据或运行态秘密，也不自动发送、发布、部署或付费。
插件声明 Hook 只证明它携带生命周期定义，不证明当前环境信任或启用了它，更不证明它已经执行；Hook 也不是独立执行器。练习不运行 Hook、不修改信任状态，只记录事件名、matcher 和脱敏观察。

### 6. 提示词练习

```text
合成场景：一家虚构团队描述了一个与本插件相关的任务。请列出至多两个候选 skill，说明为什么选择或排除；只做路由分析。
```

### 7. 可观察验收清单

- [ ] 能说出插件名、版本与 skill 数量。
- [ ] 知道第一课是总览，后续每个 canonical skill 各占一个单元。
- [ ] 调用记录同时包含插件名、slug 和 display name。
- [ ] 能说明 Ponytail Hook 位于本插件课程，而不是被误归入通用 CX/GS 课程。
- [ ] 能分别说明 Hook 的携带、信任、启用和实际执行证据，并知道它不是独立执行器。
- [ ] 输出只含路由、理由和停止条件，没有真实外部副作用。

## PT03 ponytail:全库瘦身审计

### 1. 用途

建议用时：10–15 分钟。

扫描全仓库过度工程并列出可删除、简化或替换为标准库的项。本单元训练的核心判断是：场景属于“对整个仓库做过度工程审计并按可删规模排序”时选择它。

### 2. 适用与不适用场景

- 适用：对整个仓库做过度工程审计并按可删规模排序。
- 不适用：只审查当前 diff，或需要正确性和安全审查。

### 3. 输入/输出

- 输入：完整仓库树与应排除的构建、依赖目录。
- 输出：带 delete、stdlib、native、yagni、shrink 标签的一次性报告。

### 4. 最小调用模板

```text
使用插件 ponytail，显式调用 $ponytail:ponytail-audit（ponytail:全库瘦身审计）。输入均为合成材料；只输出执行方案、停止条件和验收清单，不执行写入、发送、发布、部署、安装或付费操作。
```

### 5. 边界与风险

只报告不修复；正确性、安全和性能问题交给普通审查。任何真实账户、客户数据、凭证或外部写入都不属于本单元练习。

占位符说明：`<N>` 是可减少行数，`<M>` 是可移除依赖数；两者必须来自审计发现，不能预估。

### 6. 提示词练习
